# Chơi Pokémon trong Minecraft: Cobblemon, Pixelmon và server cho người Việt

Muốn bắt và đấu Pokémon trong Minecraft thì cần Minecraft **Java Edition** cộng với một mod Pokémon. Hai mod được chơi nhiều nhất là Cobblemon và Pixelmon. Trang này nói hai mod khác nhau thế nào và cách vào chơi cùng người Việt.

## Cần gì để chơi

- Minecraft Java Edition trên máy tính: Windows, macOS hoặc Linux.
- Một mod Pokémon: Cobblemon hoặc Pixelmon.
- Nếu chơi trên server: đúng bản Minecraft, đúng mod và bộ mod phụ mà server dùng.

Minecraft Bedrock, Minecraft PE trên điện thoại và bản máy console không chạy được Cobblemon hay Pixelmon.

## Cobblemon và Pixelmon khác gì

- **Cobblemon:** mod mã nguồn mở, giấy phép MPL-2.0, chạy trên Fabric và NeoForge. Bản 1.7.3 cho Minecraft 1.21.1 ra ngày 31/01/2026. Tải trên Modrinth hoặc CurseForge.
- **Pixelmon** (Pixelmon Reforged): mod Pokémon có từ lâu hơn, chạy trên Forge, bản cho Minecraft 1.21.1 dùng NeoForge. Tải ở reforged.gg hoặc CurseForge.

Hai mod không vào chung server được. Server Cobblemon cần máy bạn cài Cobblemon, server Pixelmon cần Pixelmon, và cả hai đều cần đúng phiên bản server đang chạy.

## Chơi một mình hay vào server

- **Chơi một mình:** cài Cobblemon bản gốc bằng Modrinth App, các bước ở trang [Cách tải Cobblemon](cach-tai-cobblemon.md).
- **Chơi cùng người Việt:** vào một server Cobblemon. Server thường cần đúng bộ mod riêng, nên dùng launcher của server sẽ đỡ lỗi nhất.

## Server Pokémon cho người Việt: Coco Cobblemon

Coco Cobblemon là server Minecraft Java chơi Cobblemon 1.7.3 trên Minecraft 1.21.1, của cộng đồng người Việt, địa chỉ `coco.ultramc.co`. Vào game bằng CocoLauncher: nhập tên, bấm **Chơi**, launcher tự cài Java, Minecraft, Fabric và đúng bộ mod.

Trong server có Đấu Xếp Hạng tính Elo, BattleTower 555 tầng, Gym, Bang Hội Chiến, Raid Thế Giới và Legendary tích luỹ: server càng lâu chưa có Legendary thì tỉ lệ càng tăng. Menu và hướng dẫn bằng tiếng Việt. Xem thêm [Server Cobblemon Việt Nam: Coco Cobblemon](server-cobblemon-viet-nam.md) và [Tải CocoLauncher](tai-cocolauncher.md).

## Hỏi nhanh

**Minecraft PE có chơi Pokémon được không?**
Cobblemon và Pixelmon không chạy trên Bedrock hay PE. Trên Android, CocoLauncher Android là bản thử nghiệm chạy Java Edition, cần máy từ 6 GB RAM, xem [Chơi Cobblemon trên điện thoại](cobblemon-dien-thoai.md).

**Cài Pixelmon rồi vào server Cobblemon được không?**
Không. Mỗi server chỉ nhận đúng mod và đúng phiên bản của nó.

**Có mất phí không?**
Cobblemon và Pixelmon tải không mất phí. Tải CocoLauncher và vào server Coco Cobblemon cũng không mất phí.
