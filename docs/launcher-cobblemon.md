# Launcher nào để chơi Cobblemon? Modrinth App, CurseForge, Prism Launcher, CocoLauncher

Cobblemon là mod cho Minecraft Java Edition, nên cần một launcher cài được mod. Chọn theo việc bạn muốn làm: chơi một mình, vào một server, hay chơi trên điện thoại.

## Chọn nhanh

| Bạn muốn | Nên dùng |
|---|---|
| Chơi Cobblemon một mình, bản gốc | Modrinth App với Cobblemon Official Modpack |
| Đã quen CurseForge, muốn dùng modpack trên đó | CurseForge App |
| Tự quản lý nhiều bản cài, nhiều phiên bản | Prism Launcher |
| Vào server Coco Cobblemon | CocoLauncher |
| Chơi trên Android | CocoLauncher Android (thử nghiệm, chỉ cho server Coco) |

## Từng launcher

**Modrinth App.** Miễn phí, có bản Windows, macOS, Linux. Tìm Cobblemon Official Modpack trong tab Modpacks, bấm Install, app tự tải đúng Minecraft, Fabric và mod phụ thuộc. Hợp với người mới chơi một mình. Các bước ở trang [Cách tải Cobblemon](cach-tai-cobblemon.md).

**CurseForge App.** Miễn phí, có nhiều modpack Cobblemon do cộng đồng làm. Hợp nếu bạn đã dùng CurseForge cho mod khác.

**Prism Launcher.** Mã nguồn mở, có bản Windows, macOS, Linux, nhập được modpack từ Modrinth và CurseForge. Hợp với người muốn tự chỉnh từng bản cài; người mới sẽ thấy nhiều tuỳ chọn hơn.

**CocoLauncher.** Launcher riêng của server Coco Cobblemon, có bản Windows (Microsoft Store), macOS và Android thử nghiệm. Nhập tên, bấm **Chơi**, launcher tự cài Java, Minecraft, Fabric và đúng bộ mod của server, mod tự cập nhật theo server. CocoLauncher chỉ dùng để vào Coco Cobblemon, không dùng để chơi một mình hay vào server khác. Tải ở trang [Tải CocoLauncher](tai-cocolauncher.md).

## Vào server thì cần gì

Mỗi server Cobblemon cần đúng phiên bản Minecraft, Cobblemon và bộ mod của server đó. Launcher chung như Modrinth App vào được server nếu server cung cấp modpack để cài; server có launcher riêng thì dùng launcher đó sẽ ít lỗi nhất. Coco Cobblemon chạy Minecraft Java 1.21.1, Fabric, Cobblemon 1.7.3 và cần bộ mod riêng, nên dùng CocoLauncher.

## Hỏi nhanh

**Minecraft Bedrock hay PE dùng được launcher nào?**
Không launcher nào ở trên cài Cobblemon vào Bedrock hay PE, vì Cobblemon là mod cho Java Edition. Trên Android, CocoLauncher Android là bản thử nghiệm chạy Java Edition để vào Coco Cobblemon, xem [Chơi Cobblemon trên điện thoại](cobblemon-dien-thoai.md).

**Launcher có mất phí không?**
Modrinth App, CurseForge App, Prism Launcher và CocoLauncher đều tải không mất phí.
