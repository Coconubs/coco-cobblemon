# Cobblemon server in Vietnam: Coco Cobblemon

Coco Cobblemon is a Minecraft Java server for the Cobblemon mod, run by and for the Vietnamese community. It is in Season 2 on Minecraft 1.21.1 with Fabric and Cobblemon 1.7.3. Players join through the server's own launcher, CocoLauncher.

| | |
|---|---|
| **Address** | `coco.ultramc.co` |

| **Language** | Vietnamese, with an English option in the launcher and the in-game menu |

## What you can do on the server

Most new players start by catching Pokémon, then move on to battles and guilds.

- Ranked battles: 4v4 Doubles with Elo and 6v6 Singles, with a sound alert when a match is found.
- Battle Tower with 555 floors, gyms, and Expeditions with 3 runs a day.
- Accumulating Legendary chance: the longer the server goes without a Legendary, the higher the chance, shown on the HUD. Legendary Golden Hours run on Saturday and Sunday, 20:00-22:00 Vietnam time.
- Guilds: Guild Wars, Guild Bosses, guild quests, and a private land lock for each member.
- World Raids and Bounty NPCs appear on a schedule.
- Daily play: check-in rewards, Battle Pass, jobs, fishing with a collection book, and a Rank Kit every 3 days.

## How to join

1. Download CocoLauncher from the [Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H) on Windows, or pick another build from the [download table](../README.en.md#download-cocolauncher).
2. Enter a player name and press **Play**. The launcher installs Java, Minecraft, Fabric and the server's mod set.
3. In game, type `/menu` to open the guide.

The server needs its exact mod set. Joining with another launcher usually ends with missing mods or a version mismatch.

## Which devices work

- Windows and macOS: yes.
- Android: experimental build that runs Java Edition, needs 6 GB of RAM or more.
- iPhone and iPad: not available.
- Minecraft Bedrock and Pocket Edition: no, Cobblemon is a Java Edition mod.

## Quick answers

**Is there a Cobblemon server in Vietnam?**
Yes. Coco Cobblemon is a Vietnamese Cobblemon server with Vietnamese menus, guides and announcements.

**Can I join from outside Vietnam?**
Yes. Anyone can download CocoLauncher and join. Most players and most of the chat are Vietnamese, and the menus can be switched to English.

**Where do I get help?**
Ask on [Discord](https://discord.gg/hyspace). The Discord server is called Hyper Space.
