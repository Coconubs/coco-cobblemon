# Cách vào server Coco Cobblemon

Coco Cobblemon là server Minecraft Java chơi mod Cobblemon dành cho cộng đồng người Việt, vào game bằng launcher riêng CocoLauncher. Trang này đi từ lúc tải launcher tới khi mở Menu trong game.

| | |
|---|---|
| **Địa chỉ server** | `coco.ultramc.co` |
| **Phiên bản** | Minecraft Java 1.21.1, Fabric, Cobblemon 1.7.3 |
| **Launcher** | CocoLauncher |
| **Chi phí** | Tải launcher và vào server không mất phí. Có Rank và Battle Pass Premium không bắt buộc |

## 5 bước vào server

1. **Tải launcher:** vào trang [Tải CocoLauncher](tai-cocolauncher.md), chọn đúng hệ điều hành.
2. **Nhập tên:** 3 đến 16 ký tự, chữ không dấu, số hoặc dấu gạch dưới.
3. **Bấm Chơi:** lần đầu launcher tải Java, Minecraft, Fabric và gói mod, nên dùng mạng ổn định. Những lần sau chỉ tải phần thay đổi.
4. **Vào game:** launcher tự kết nối tới server. Làm theo hướng dẫn đăng ký trên màn hình.
5. **Mở Menu:** gõ `/menu`. Trong Menu có Hướng dẫn tiếng Việt cho từng tính năng.

## Việc nên làm ngày đầu

1. Liên kết Discord và điểm danh.
2. Mở Battle Pass, làm nhiệm vụ ngày.
3. Nhận việc bằng `/nghenghiep`.
4. Làm Ải Viễn Chinh, 3 lượt mỗi ngày.
5. Leo BattleTower để nhận BP mỗi sáng.

## Tự kết nối bằng launcher khác được không?

Không nên. Server cần đúng bộ mod, launcher khác sẽ thiếu mod hoặc sai phiên bản. Gặp lỗi thì xem [Sửa lỗi CocoLauncher](sua-loi-cocolauncher.md).

## Chơi bằng Minecraft Bedrock được không?

Không. Cobblemon là mod cho Java Edition. Trên điện thoại Android có thể dùng CocoLauncher Android, đây là bản thử nghiệm chạy Java Edition. Hiện chưa có bản iOS.
