# Cách vào server Coco Cobblemon

Coco Cobblemon là server Minecraft Java chơi mod Cobblemon dành cho cộng đồng người Việt, vào game bằng launcher riêng CocoLauncher. Trang này đi từ lúc tải launcher tới khi mở Menu trong game.

**Bài này đã chuyển sang trang Documents của Coco Cobblemon:** [https://coconubs.github.io/cach-vao-server/](https://coconubs.github.io/cach-vao-server/)

Bản trên trang Documents luôn là bản mới nhất. Trang chính: [README](../README.md) · Discord: https://discord.gg/hyspace
