# Play Cobblemon on Android: Coco Cobblemon

Cobblemon is a mod for Minecraft Java Edition, so it does not install into Minecraft Pocket Edition or Bedrock. To play on a phone, the Coco Cobblemon server has CocoLauncher Android, an experimental app that runs Java Edition on the Android device and joins the same server as PC players.

## What your phone needs

- 6 GB of RAM or more, 8 GB or more recommended.
- A mid-range chip or better.
- About 2 GB of free storage.
- About 400 MB to download on first launch, so use Wi-Fi.

Weaker phones may still start the game, but they tend to stutter or close in busy areas.

## Install

1. Download [CocoLauncher-Android.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android.apk).
2. Open the file. If Android asks, allow your browser to install unknown apps.
3. Open CocoLauncher, enter a player name and press **Play**.

If a Chrome download sits at 100%, pull down the notification shade: Chrome is usually waiting for you to confirm keeping the .apk file.

The Android build uses the Coco Lite pack, about 125 mods. It is lighter than the PC pack and still joins the same server.

## PC emulators (MuMu, LDPlayer)

Emulators use a separate build: [CocoLauncher-Android-GiaLap.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android-GiaLap.apk). If the computer runs Windows, the [Windows launcher](../README.en.md#download-cocolauncher) is lighter and more stable than an emulator.

## iPhone and iPad

Not available.

## Tips for weaker phones

- Close background apps before you play.
- Lower the render distance in the graphics settings.
- For long sessions keep the phone plugged in and cool. A hot phone slows itself down.
