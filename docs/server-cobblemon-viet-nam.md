# Server Cobblemon Việt Nam: Coco Cobblemon

Coco Cobblemon là server Minecraft Java chơi mod Cobblemon dành cho cộng đồng người Việt, vào game bằng launcher riêng CocoLauncher. Server chạy Minecraft 1.21.1 với Fabric và Cobblemon 1.7.3.

**Bài này đã chuyển sang trang Documents của Coco Cobblemon:** [https://coconubs.github.io/server-cobblemon-viet-nam/](https://coconubs.github.io/server-cobblemon-viet-nam/)

Bản trên trang Documents luôn là bản mới nhất. Trang chính: [README](../README.md) · Discord: https://discord.gg/hyspace
