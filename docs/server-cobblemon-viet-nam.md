# Server Cobblemon Việt Nam: Coco Cobblemon

Coco Cobblemon là server Minecraft Java chơi mod Cobblemon dành cho cộng đồng người Việt, vào game bằng launcher riêng CocoLauncher. Server đang ở Mùa 2, chạy Minecraft 1.21.1 với Fabric và Cobblemon 1.7.3.

| | |
|---|---|
| **Địa chỉ** | `coco.ultramc.co` |
| **Phiên bản** | Minecraft Java 1.21.1, Fabric, Cobblemon 1.7.3 |
| **Ngôn ngữ** | Tiếng Việt, có nút chọn tiếng Anh trong menu |
| **Vào game** | CocoLauncher cho Windows, macOS, Android |
| **Chi phí** | Tải launcher và vào server không mất phí |
| **Discord** | [discord.gg/hyspace](https://discord.gg/hyspace) |

## Chơi gì trên server

Người mới thường bắt đầu bằng bắt Pokémon, sau đó mới đánh trận và vào bang. Các hệ thống chính:

- Đấu Xếp Hạng: Đấu Đôi 4v4 tính Elo và Đấu Đơn 6v6. Ghép được trận thì có âm thanh báo.
- BattleTower 555 tầng, Gym, Ải Viễn Chinh 3 lượt mỗi ngày.
- Legendary tích luỹ: server càng lâu chưa có Legendary thì tỉ lệ càng tăng, xem ngay trên HUD. Giờ Vàng Legendary vào Thứ 7 và Chủ Nhật, 20h-22h.
- Bang hội: Bang Hội Chiến, Boss Bang, nhiệm vụ bang, khoá đất riêng cho từng thành viên.
- Raid Thế Giới và NPC Tiền Thưởng xuất hiện theo giờ.
- Việc hằng ngày: điểm danh, Battle Pass, Nghề nghiệp, câu cá có sổ sưu tập, Kit Rank mỗi 3 ngày.

Danh sách đầy đủ ở trang [Tính năng Mùa 2](tinh-nang.md). Thay đổi mới nhất ghi ở [Nhật ký cập nhật](cap-nhat.md).

## Vào server thế nào

1. Tải CocoLauncher ở trang [Tải CocoLauncher](tai-cocolauncher.md).
2. Nhập tên trong game, bấm **Chơi**. Launcher tự cài Java, Minecraft, Fabric và đúng bộ mod của server.
3. Vào game, gõ `/menu` để mở Hướng dẫn tiếng Việt.

Server cần đúng bộ mod, nên vào bằng launcher khác thường bị thiếu mod hoặc sai phiên bản. Chi tiết từng bước ở [Cách vào server](cach-vao-server.md).

## Máy nào chơi được

- Windows, macOS: chơi được, cài launcher như trên.
- Android: có bản thử nghiệm, cần RAM từ 6 GB. Xem [Chơi Cobblemon trên điện thoại](cobblemon-dien-thoai.md).
- iPhone, iPad: chưa có.
- Minecraft Bedrock, PE: không chơi được, vì Cobblemon là mod cho Java Edition.

## Hỏi nhanh

**Có server Cobblemon nói tiếng Việt không?**
Có. Coco Cobblemon dùng tiếng Việt cho launcher, menu, hướng dẫn và thông báo. Một số chữ của Cobblemon và mod khác vẫn có thể hiện tiếng Anh.

**Server có chạy cả ngày không?**
Có. Buổi tối là lúc đông người chơi. Lịch sự kiện và bảo trì báo trên Discord.

Xem trước trang [Sửa lỗi CocoLauncher](sua-loi-cocolauncher.md), chưa được thì hỏi trên [Discord](https://discord.gg/hyspace).
