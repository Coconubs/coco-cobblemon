# Chơi Cobblemon trên điện thoại Android

Cobblemon là mod cho Minecraft Java Edition, nên không cài được vào Minecraft PE hay Bedrock. Muốn chơi trên điện thoại, server Coco Cobblemon có CocoLauncher Android, bản thử nghiệm chạy Java Edition ngay trên máy Android.

**Bài này đã chuyển sang trang Documents của Coco Cobblemon:** [https://coconubs.github.io/cobblemon-dien-thoai/](https://coconubs.github.io/cobblemon-dien-thoai/)

Bản trên trang Documents luôn là bản mới nhất. Trang chính: [README](../README.md) · Discord: https://discord.gg/hyspace
