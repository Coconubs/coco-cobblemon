# Tải CocoLauncher (Coco Launcher) cho Windows, macOS, Android

CocoLauncher là launcher của server Coco Cobblemon, tự cài Java, Minecraft, Fabric và gói mod để người chơi vào server chỉ bằng một nút. Nhà phát hành là Coconubs.

| Nền tảng | Link tải |
|---|---|
| Windows (khuyên dùng) | [Microsoft Store](https://apps.microsoft.com/detail/9NPG31VS7T2H?cid=github) |
| Windows, file cài | [CocoLauncher-Setup.exe](https://github.com/Coconubs/cocolauncher-pack/releases/download/launcher/CocoLauncher-Setup.exe) |
| macOS M1-M4 và mới hơn (chip Apple) | [CocoLauncher-Mac-AppleSilicon.dmg](https://github.com/Coconubs/cocolauncher-pack/releases/download/launcher/CocoLauncher-Mac-AppleSilicon.dmg) |
| macOS Intel | [CocoLauncher-Mac-Intel.dmg](https://github.com/Coconubs/cocolauncher-pack/releases/download/launcher/CocoLauncher-Mac-Intel.dmg) |
| Android (thử nghiệm, RAM từ 6 GB) | [CocoLauncher-Android.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android.apk) |
| Android trên giả lập PC (MuMu, LDPlayer) | [CocoLauncher-Android-GiaLap.apk](https://github.com/Coconubs/cocolauncher-pack/releases/download/android-app/CocoLauncher-Android-GiaLap.apk) |
| iOS, Linux | Chưa có |

Mọi file nằm ở [Releases của Coconubs/cocolauncher-pack](https://github.com/Coconubs/cocolauncher-pack/releases), mỗi file có mã SHA-256 để đối chiếu. Bản .exe chưa có chữ ký số nên SmartScreen có thể cảnh báo, nên ưu tiên Microsoft Store. Chỉ tải từ các link trên, bản đăng lại ở trang khác có thể đã bị sửa.
