# Tải CocoLauncher (Coco Launcher) cho Windows, macOS, Android

CocoLauncher là launcher của server Coco Cobblemon, tự cài Java, Minecraft, Fabric và gói mod để người chơi vào server chỉ bằng một nút. Nhà phát hành là Coconubs.

**Bài này đã chuyển sang trang Documents của Coco Cobblemon:** [https://coconubs.github.io/cocolauncher/](https://coconubs.github.io/cocolauncher/)

Bản trên trang Documents luôn là bản mới nhất. Trang chính: [README](../README.md) · Discord: https://discord.gg/hyspace
