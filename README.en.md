# Coco Cobblemon

Coco Cobblemon is a Vietnamese community Minecraft Java server running the Cobblemon mod, played through its own launcher, CocoLauncher.

[Tiếng Việt](README.md)

| | |
|---|---|
| **Server address** | `coco.ultramc.co` |
| **Version** | Minecraft Java 1.21.1, Fabric, Cobblemon 1.7.3 |
| **Language** | Vietnamese, with an English option in the in-game menu |
| **Launcher** | CocoLauncher |
| **Discord** | [discord.gg/hyspace](https://discord.gg/hyspace) |

## How to join

1. Download CocoLauncher from the table above.
2. Enter a player name and press Play. The launcher installs the right versions and modpack.
3. Type `/menu` in game for the guide.

The server needs its exact mod set, so other launchers will be missing mods or run the wrong version.

## Features

- Ranked battles: 4v4 Doubles with Elo and 6v6 Singles.
- Battle Tower with 555 floors and a ruleset per floor.
- World Raids, Guild Bosses and Guild Wars.
- Accumulating Legendary spawn chance and Legendary Golden Hours on Saturday and Sunday, 20:00-22:00 Vietnam time.
- Battle Pass, jobs, expeditions and fishing.

## FAQ

### What is the Coco Cobblemon server IP?

The address is `coco.ultramc.co`, Minecraft Java 1.21.1. CocoLauncher connects automatically.

### Is it free to play?

Downloading CocoLauncher and joining the server is free. Ranks and the Premium Battle Pass are optional.

### What computer do I need?

Windows 10 or 11 (64-bit), or a Mac with Apple silicon or Intel. The launcher gives the game 2 to 4 GB of RAM by default, so 8 GB of RAM or more is recommended. There is no Linux build yet.

### Can I play on Bedrock or Pocket Edition?

No. Cobblemon is a Java Edition mod. On Android, CocoLauncher Android is an experimental build that runs Java Edition and needs at least 6 GB of RAM, see [Play Cobblemon on Android](docs/cobblemon-android.md). There is no iOS version.

### Do I need to speak Vietnamese?

The community and most server content are Vietnamese. The launcher and the in-game menu have an English option, and some content from Cobblemon and other mods may appear in English.

### What is Hyper Space?

Hyper Space is the name of the Coco Cobblemon community Discord server: https://discord.gg/hyspace. Some older videos call the server Coco's Hyper Space; it is the same server, Coco Cobblemon.
