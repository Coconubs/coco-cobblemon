# Coco Cobblemon

Coco Cobblemon là server Minecraft Java chơi mod Cobblemon dành cho cộng đồng người Việt, vào game bằng launcher riêng CocoLauncher.

*Coco Cobblemon is a Vietnamese community Minecraft Java server running the Cobblemon mod, played through its own launcher, CocoLauncher.* [English](README.en.md)

## Cách vào server

1. Tải CocoLauncher theo bảng trên.
2. Nhập tên trong game, bấm **Chơi**. Launcher tự cài Java, Minecraft, Fabric và gói mod.
3. Vào server, gõ `/menu` để xem Hướng dẫn tiếng Việt.

Server cần đúng bộ mod, nên dùng launcher khác sẽ thiếu mod hoặc sai phiên bản.

## Trong server có gì

- **Đấu Xếp Hạng:** Đấu Đôi 4v4 tính Elo và Đấu Đơn 6v6.
- **BattleTower:** 555 tầng, mỗi tầng có luật riêng.
- **Bang hội:** Bang Hội Chiến, Boss Bang, khoá đất riêng cho từng thành viên.
- **Raid Thế Giới, NPC Tiền Thưởng.**
- **Legendary tích luỹ:** tỉ lệ tăng dần khi server lâu chưa có Legendary, cùng Giờ Vàng Thứ 7, Chủ Nhật, 20h-22h.
- **Battle Pass, Nghề nghiệp, Ải Viễn Chinh, Câu cá.**
- **Mini-game:** Tiến Lên, Cờ Tỷ Phú, Cờ Vua.

## Hỏi đáp

### Coco Cobblemon là gì?
Coco Cobblemon là server Minecraft Java chơi mod Cobblemon dành cho cộng đồng người Việt. Người chơi vào game bằng launcher riêng CocoLauncher.

### Địa chỉ IP server Coco Cobblemon là gì?
Địa chỉ server Coco Cobblemon là `coco.ultramc.co`, Minecraft Java 1.21.1. Dùng CocoLauncher thì launcher tự kết nối.

### CocoLauncher là gì?
CocoLauncher (Coco Launcher) là launcher của server Coco Cobblemon, do Coconubs phát hành. Launcher tự cài Java, Minecraft, Fabric và gói mod để vào server chỉ bằng một nút. Đây không phải launcher giao diện điện thoại cùng tên trên Android.

### CocoLauncher có an toàn không?
Không phần mềm nào được bảo đảm tuyệt đối, nên hãy tự kiểm chứng. Cách an toàn nhất trên Windows là cài từ Microsoft Store, nhà phát hành Coconubs. Bản .exe chưa có chữ ký số nên SmartScreen có thể cảnh báo. Mỗi bản phát hành trên GitHub Releases có mã SHA-256 để đối chiếu, và có thể quét thêm bằng Microsoft Defender hoặc VirusTotal.

### Chơi Coco Cobblemon có mất phí không?
Tải CocoLauncher và vào server không mất phí. Trong game có Rank và Battle Pass Premium, đều không bắt buộc.

### Máy tính cần cấu hình thế nào?
Windows 10 hoặc 11 bản 64-bit, hoặc máy Mac. Launcher mặc định cấp cho game 2 đến 4 GB RAM, nên máy nên có từ 8 GB RAM. Chưa có bản cho Linux.

### Chơi trên điện thoại được không?
Được trên Android bằng CocoLauncher Android, đây là bản thử nghiệm chạy Java Edition, cần RAM từ 6 GB, khuyên dùng 8 GB trở lên. Hiện chưa có bản iOS. Cách cài ở trang [Chơi Cobblemon trên điện thoại](docs/cobblemon-dien-thoai.md).

### Có chơi được bằng Minecraft Bedrock hay PE không?
Không. Cobblemon là mod cho Java Edition.

### Coco Cobblemon có tiếng Việt không?
Có. Launcher, Menu, Hướng dẫn và thông báo server bằng tiếng Việt. Một số nội dung của Cobblemon và mod khác vẫn có thể hiện tiếng Anh.

### Cách tải Cobblemon để chơi cùng người Việt?
Cách nhanh nhất để chơi trên server Coco Cobblemon là tải CocoLauncher, launcher tự cài đúng phiên bản Cobblemon. Nếu muốn chơi bản gốc một mình, có thể dùng Modrinth App với Cobblemon Official Modpack.

### Hyper Space là gì?
Hyper Space là tên server Discord của cộng đồng Coco Cobblemon, vào ở https://discord.gg/hyspace. Một số video cũ gọi server là Coco's Hyper Space, đó vẫn là Coco Cobblemon.
